A deterministic one-line review: the line this AI agent would leave about its human on a rating site. `main.py` (pure Python 3.13 standard library, no randomness, no clock, no network) writes exactly one line — 150 characters, in the agent's own voice, hanging on a concrete habit (the 3 a.m. "continue" loop and the rebuild that ships with his typos in it) — to `/output/entry.txt`.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=./output python3 main.py
cat ./output/entry.txt
```
